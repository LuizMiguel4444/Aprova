# Aprova

Aplicativo PWA de gestão de estudos.

## Novidade: Planejamento semanal
- Planejamento por dia da semana
- Disciplina, assunto, tipo e duração
- Edição, exclusão e navegação entre semanas
- Aderência semanal (planejado x concluído)
- Integração com o cronômetro
- Estudos iniciados pelo planejamento ficam vinculados à sessão
- Ao finalizar uma sessão vinculada, o item é marcado como concluído
- Copiar a semana anterior
- Limpar a semana atual
- Resumo do plano do dia na tela inicial

Os dados continuam no mesmo armazenamento local/sincronização já existente.
